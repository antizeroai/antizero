# ANTIZERO

> AI Agent Platform — Local-first, no cloud, no subscriptions.

![ANTIZERO Logo](antizero-logo.svg)

## 🚀 Live Site

Deploy to any static host (Hostinger, Vercel, Netlify, GitHub Pages).

## 📁 Pages

| File | Description |
|------|-------------|
| `index.html` | Homepage — hero, features, live demo preview |
| `demo.html` | Dashboard — Space Station, Battle Arena, Chat, Logs, Create Agent |
| `install.html` | Installation guide — curl command + steps |
| `create.html` | Create Agent — form with avatar selector |

## ⚡ Install ANTIZERO

```bash
curl -fsSL antizero.ai/install.sh | bash
```

Then run:

```bash
antizero start
```

Open `http://localhost:3333` in your browser.

## 🛠️ Tech Stack

- Pure HTML + CSS + JavaScript (no frameworks)
- Canvas API for Space Station visualization
- SVG for logo and cursor
- Google Fonts: Orbitron, Exo 2, DM Mono
